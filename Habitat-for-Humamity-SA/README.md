1. Project Overview

This project is a website created for Habitat for Humanity South Africa. The website provides information about the organisation, its work and different ways that people can get involved.

The website was initially created using HTML and CSS as part of Part 1 of the assignment. Part 2 focused on improving the website's visual appearance, styling and responsive design.

2. Website Goals and Objectives

The main goals of the website are:

- To provide information about Habitat for Humanity South Africa.
- To explain the organisation's work and programmes.
- To allow visitors to make enquiries.
- To provide contact information and different locations.
- To create a simple and easy-to-use website.
- To provide information about volunteering and sponsorship.

3. Key Features and Functionality

The website includes:

- Home page with a hero image.
- About Us page.
- Programmes page.
- Enquiry page with a form.
- Contact page with multiple locations and a contact form.
- Navigation menu linking all five pages.
- Responsive layouts for different screen sizes.
- External CSS styling.
- Images stored in a separate images folder.

4. Website Pages

The website consists of five HTML pages:

Part 2 – CSS Styling and Responsive Design

7. CSS Improvements

Part 2 focused on improving the visual design of the Habitat for Humanity South Africa website and making it responsive on different screen sizes.

The website was updated using an external CSS stylesheet located in "css/style.css".

The following CSS improvements were made:

- Added a CSS reset to remove default browser spacing.
- Added consistent fonts, colours, spacing and sizing.
- Used relative units such as "rem" and "%".
- Used Flexbox for the programme layout and enquiry/contact forms.
- Added borders, rounded corners and box shadows.
- Added hover, focus and active effects to navigation links, buttons and other interactive elements.
- Improved the styling of headings, paragraphs, forms and buttons.
- Added responsive styling for images.
- Improved the hero section on the Home page.

8. Responsive Design

The website was tested at three different screen sizes to check how the layout responds to different devices.

Desktop

The website was tested at 1366 × 768 pixels. The navigation, content sections, images and forms were checked to ensure that they displayed correctly on a desktop screen.

Tablet

The website was tested at 768 × 1024 pixels. The content resized to fit the smaller screen, and the navigation and programme sections were checked for proper alignment.

Mobile

The website was tested at 375 × 667 pixels. The navigation adapted to the smaller screen, the website title adjusted and the content was checked to ensure that it fitted within the mobile viewport.

9. Responsive CSS Breakpoints

The CSS includes media queries for different screen sizes:

- Tablet: "max-width: 900px"
- Mobile: "max-width: 600px"

These breakpoints adjust the navigation, headings, content sections, forms, images and spacing for smaller screens.
